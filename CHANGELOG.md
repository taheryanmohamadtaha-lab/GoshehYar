# Changelog

## [Unreleased] - Phase 4 (advanced)
- System monitor (CPU, RAM, disks, network, battery, uptime), read only while its window is open
- Clipboard history (text only, off by default, pin/search/clear, skips password-manager copies, not part of backups)
- Per-tool global shortcuts that open a tool directly
- Advanced appearance: panel corner radius and show/hide animation length

## [Unreleased] - Phase 3 (daily widgets)
- Clock (world clocks), calendar (Jalali/Gregorian, events with exact reminders), weather (Open-Meteo, cached), To-Do with due date/time and exact reminders, timer/stopwatch/Pomodoro, calculator with percent, unit converter, password generator and date tools

## [Unreleased] - Phase 2 (tools)
- Screenshot, audio recorder, music player, notes (SQLite) with reminders, backup/restore system

## [Unreleased] - Phase 1 (core)
- Floating panel on any screen edge (left/right/top/bottom), corner/center alignment, multi-monitor, DPI aware
- Auto-hide with a thin handle, reveal on mouse approach, pin, always-on-top, full-screen awareness
- Global hotkey (default Ctrl+Alt+Space), changeable with conflict detection
- System tray icon: show/hide, hide completely, settings, restart, exit
- Settings window (live apply, saved as JSON), 8 themes, accent color, font, Persian/English, Persian/English digits
- Single-instance, crash isolation, start with Windows
- Inno Setup installer + portable zip built by GitHub Actions
